# CML Assistant Frontend

React frontend for the CML Patient Assistant.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open `http://localhost:5173`.

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Tech Stack

- React 19 + TypeScript 6
- Vite 8
- MUI 6 + MUI X Charts
- react-router-dom
